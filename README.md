# Intelligent CV Matching & Job Recommendation System

Problème : un étudiant ou jeune diplômé passe du temps à lire plusieurs offres et à comparer
manuellement leurs exigences avec son CV.

Le projet est dans [`cv-matching/`](cv-matching/README.md) :

```bash
cd cv-matching
pip install -e ".[all]"
cvmatch pipeline --offline   # démo hors-ligne de tout le pipeline
```
